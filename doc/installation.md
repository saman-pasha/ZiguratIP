# Installation

After you have downloaded any compressed file for your platform [here](../download.html#main), you should extract it in a path that you wish to be Zigurat home. Zigurat home consists all of data, headers, configs, temporaries, binaries and libraries files.
ziguratip process should know about the ZiguratIP home path to find all it needs. So do not forget to create ZIGURATIP_HOME enviroment variable that contains installation path.
All binaries and libraries in ZiguratIP should be available in PATH enviroment variable, for doing these, append ZIGURATIP_HOME/bin, ZIGURATIP_HOME/lib, ZIGURATIP_HOME/ld to the PATH enviroment variable.
Considered to configure your informational platform before run. If c++ compiler is not in PATH, COMPILER/CPP should be configured. Configuration documentation is available [here](configuration.md). Please ask me your questions and send me your feedbacks at:
