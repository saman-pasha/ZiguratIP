# Data Types

## Object

Object is the type of the NULL literal. It is a distinct type that is not itself a type.

## Bool

Bool nullable type, capable of holding one of the two values: TRUE or FALSE.

## Char

Char nullable type for signed character representation.

## Byte

Byte nullable type will have signed representation and will have width of at least 8 bits.

## UByte

UByte nullable type will have unsigned representation and will have width of at least 8 bits.

## Short

Short nullable type will have signed representationand will have width of at least 16 bits.

## UShort

UShort nullable type will have unsigned representation and will have width of at least 16 bits.

## Int

Int nullable basic integer type will have signed representation and will have width of at least 32 bits.

## UInt

UInt nullable type will have unsigned representation and will have width of at least 32 bits.

## Long

Long nullable type will have signed representation and will have width of at least 64 bits.

## ULong

ULong nullable type will have unsigned representation and will have width of at least 64 bits.

## Float

Float nullable single precision 32 bit floating point type.

## Double

Double nullable double precision 64 bit floating point type.

## Real

Real nullable extended precision 80-bit x87 floating point type.

## Timestamp

Timestamp nullable arithmetic type capable of representing times.

## String

String nullable object that represent sequences of characters. the maximum storage size is 255.

## Text

Text nullable object that represent sequences of characters. the maximum storage size is 65,535.

## Vector

Vector nullable object that represent sequences of data types. the maximum storage size is 4,294,967,295.
