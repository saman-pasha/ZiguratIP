Welcome to Zeytun

Zeytun is the web front end of the Zigurat Informational Platform. It serves this directory as static content and compiles any request ending in .zt into a native page that runs inside the database process.

Every request is one transaction: Zeytun opens it before the page runs, commits when the page returns cleanly and rolls it back otherwise. Sessions are separate and outlive the request, carried by a cookie.

If you are seeing this page, the server is running and reading from $ZIGURATIP_HOME/http.

Elsewhere in the family:

  • Zigurat — the platform and its products
  • Memory viewer — inspect the page store and its indexes
  • RPC console — call procedures over the binary protocol

Replace this page by dropping your own index.html into $ZIGURATIP_HOME/http, or remove it and Zeytun will look for a compiled index.zt instead. The Parsi language reference lives in doc/ in the source tree.
